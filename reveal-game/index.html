빠른 사용법

상세 도움말 열기
  1. 온라인에서 처음 접속한 뒤 상단의 오프라인 사용 준비 완료를 확인합니다.
  2. 이미지 폴더 선택으로 사진이 들어 있는 폴더를 고릅니다. 사진은 서버로 전송되지 않습니다.
  3. 순서, 공개 모드, 5~300초 공개 시간, 속도 프로필을 설정합니다.
  4. 두 모니터라면 참가자 화면 열기를 누르고 새 창을 두 번째 모니터로 옮깁니다.
  5. 시작 후 정답이면 성공, 넘어가려면 실패/패스를 누르고, 판정 뒤 다음 이미지로 이동합니다.
  6. 랭킹은 별도로 직접 입력하고 행사가 끝나기 전에 JSON으로 백업합니다.
  7. 인터넷이 불안정하면 비상용 단일 HTML을 다운로드해 두 번 클릭해 실행합니다.
